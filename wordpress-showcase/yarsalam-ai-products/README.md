# YarSalam AI Products Preview — WordPress Plugin

این افزونه یک کاتالوگ فارسی RTL و پیش‌نمایش تعاملی Trust & Safety برای خانواده محصولات AI Packs ایجاد می‌کند.

## نصب
1. پوشهٔ `yarsalam-ai-products` را در `wp-content/plugins/` قرار دهید یا ZIP افزونه را نصب کنید.
2. افزونه را فعال کنید.
3. در صورت نبود صفحه‌ای با slug برابر `ai-products`، صفحهٔ «محصولات هوش مصنوعی یارسلام» به‌صورت خودکار ساخته می‌شود.
4. از منوی مدیریت WordPress با عنوان «AI Packs» وضعیت محصولات و آخرین CIها را ببینید؛ از زیرمنوی «پیش‌نمایش محصولات» لینک فرم تماس یا ایمیل را تنظیم کنید.

## Shortcode
`[yarsalam_ai_products]`

## رفتار و حریم خصوصی
- صفحه کاتالوگ محصولات و داشبورد تعاملی نمایشی شامل KPI، نمودار، صف بررسی و تنظیمات سیاست را نشان می‌دهد.
- تب‌ها، فیلتر صف، تصمیم‌های نمونه و slider آستانه فقط state مرورگر را تغییر می‌دهند؛ هیچ API یا دیتابیس فراخوانی نمی‌شود.
- داشبورد به API زنده وصل نیست؛ آمار، صف، دسته‌ها و پیام‌ها دادهٔ ساختگی هستند. هیچ متن، تصویر، کوکی، IP یا دادهٔ بازدیدکننده به Gateway ارسال نمی‌شود.
- هیچ کلید License یا Admin در مرورگر قرار نمی‌گیرد.
- صفحه قیمت قطعی، ادعای دقت یا دکمه خرید ندارد؛ وضعیت‌ها با واقعیت فعلی پروژه هماهنگ هستند.
- در زمان فعال‌سازی صفحه ساخته می‌شود، ولی افزونه صفحه موجود را بازنویسی نمی‌کند و در حذف افزونه هم صفحه را پاک نمی‌کند.

## وضعیت محصول هنگام انتشار این نسخه
- Persian Trust & Safety API: آماده ارزیابی کنترل‌شده؛ benchmark مستقل، ممیزی مجوز و تست عملیاتی باقی است.
- SEO & AI Visibility: پیش‌نمایش فنی؛ پوشش AEO و امنیت URL audit باید ارزیابی شود.
- Revenue Intelligence: در حال توسعه؛ مدل‌های Revenue و Uplift باید آموزش/ارزیابی شوند.
- Matching & Support Intelligence: در حال توسعه؛ نصب از صفر و benchmark مستقل لازم است.

## مرکز کنترل مدیر WordPress

- منوی «AI Packs» فقط برای نقش دارای `manage_options` نمایش داده می‌شود.
- آخرین GitHub Release رسمی را از API عمومی نمایش می‌دهد؛ تا وقتی Release واقعی ایجاد نشده باشد، صریحاً «هنوز نسخهٔ رسمی منتشر نشده» نشان می‌دهد و Artifact موقت CI را نسخهٔ رسمی حساب نمی‌کند.
- وضعیت Workflowهای عمومی GitHub Actions را از GitHub API می‌خواند و ۵ دقیقه cache می‌کند؛ هیچ کلید GitHub یا Secret در مرورگر قرار نمی‌گیرد.
- وضعیت کیفیت مدل تا زمان وجود Benchmark واقعی «اندازه‌گیری نشده» است.
- مصرف منابع سرور تا زمان اتصال امن عامل خصوصی «متصل نیست» نمایش داده می‌شود؛ این صفحه پورت یا endpoint خصوصی را عمومی نمی‌کند.
- برای اتصال read-only به عامل خصوصی (اختیاری)، دو constant را فقط در `wp-config.php` قرار دهید؛ آن‌ها را در تنظیمات قابل‌مشاهده، دیتابیس یا JavaScript نگذارید:

```php
define('YAP_AI_PACK_CONTROL_URL', 'http://172.18.0.1:9115');
define('YAP_AI_PACK_CONTROL_TOKEN', 'REPLACE_WITH_PRIVATE_64_CHAR_TOKEN');
```

  آدرس باید IP خصوصی RFC1918 و قابل‌دسترسی فقط از شبکهٔ داخلی باشد؛ توکن باید حداقل ۴۸ نویسهٔ تصادفی داشته باشد. نمونهٔ بالا فقط قالب است و IP/توکن واقعی سرور محسوب نمی‌شود. عامل فقط `GET /v1/status` را با هدر Bearer می‌خواند. هیچ فرمان کنترلی اجرا نمی‌شود.
- در صورت محدودیت دسترسی سرور WordPress به api.github.com، پیام خطا و لینک مستقیم Actions نمایش داده می‌شود.

## پیش‌نمایش داشبورد Safety

- **نمای کلی:** KPIهای ساختگی، نمودار روند هفتگی، تفکیک دسته‌ها و سه مورد اخیر.
- **صف بررسی:** سه کارت نمونه با دلیل پرچم‌گذاری و دکمه‌های تأیید، ارجاع و مسدودسازی. نتیجه فقط در پیش‌نمایش تغییر می‌کند.
- **سیاست‌ها:** سه دستهٔ سیاست، action select و آستانهٔ نمونه؛ گزینهٔ ذخیره فقط پیام محلی نشان می‌دهد و چیزی ذخیره نمی‌کند.
- همهٔ اعداد و متن‌ها برای نمایش UI ساخته شده‌اند و نباید به‌عنوان benchmark یا خروجی مدل استفاده شوند.
